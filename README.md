# MA GUINÉE 🇬🇳

Créé par **Marie Antoinette Filloi**.

Jeu de culture générale sur la République de Guinée — histoire, géographie, institutions, culture, citoyenneté et actualité — destiné aux élèves, à la population, au gouvernement et à l'Assemblée Nationale.

## Jouer

Ouvrir [index.html](index.html) dans un navigateur, ou héberger le dossier (ex. GitHub Pages) pour y jouer en ligne. Installable comme application sur téléphone (PWA) une fois hébergé en HTTPS.

## Contenu

- `index.html`, `style.css`, `app.js` — l'application
- `questions.js` — banque de questions par catégorie
- `manifest.json`, `sw.js`, `icons/` — support PWA (installation sur téléphone, mode hors-ligne)

Aucune dépendance ni étape de compilation : HTML/CSS/JS pur.
